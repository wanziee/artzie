Taruh foto contoh karya Sketch di folder ini. Carousel halaman `/sketch` akan membacanya otomatis.

Gunakan nama file berikut:
- sketch-01.jpg
- sketch-02.jpg
- sketch-03.jpg

Tips:
- Gunakan format `.jpg`, `.jpeg`, `.png`, atau `.webp`.
- Jika memakai nama lain, ubah daftar `gallerySlides` di `src/app/sketch/page.tsx`.
- Foto akan tampil paling baik jika memiliki ukuran dan orientasi yang mirip.

## Contoh layout Artzie Booth

Taruh gambar contoh untuk pilihan frame di folder ini. Pilihan layout di halaman `/artzie-booth` akan membacanya otomatis.

Gunakan nama file berikut:
- frame-3-vertical.jpg — 1 strip dengan 3 frame vertikal
- frame-4-vertical.jpg — 1 strip dengan 4 frame vertikal
- frame-4-square.jpg — 1 strip dengan 4 frame kotak (2 atas 2 bawah)

Jika memakai nama lain, ubah `frameSampleImages` di `src/app/artzie-booth/page.tsx`. Selama gambar belum tersedia, halaman menampilkan ilustrasi layout sebagai pengganti.
